# design.md — Visual Design System

## Principle
Plain, simple, high-contrast, large touch targets. Every feature lives in a
clearly bordered box/card.

## Color palette

| Role | Color | Hex |
|---|---|---|
| Primary | Deep leaf green | #2D6A4F |
| Primary dark | Forest green | #1B4332 |
| Background | Off-white | #F8FAF7 |
| Card background | Soft green tint | #F1F7F3 |
| Alert/Warning | Amber | #F4A300 |
| Critical alert | Red | #D64545 |
| Text primary | Charcoal | #222222 |

## Typography
- Font: Inter or Poppins
- Base size: 16px minimum
- Headings bold

## Layout rules
- Every module = rounded-xl card, soft shadow
- Icons paired with text labels
- Mobile-first
- Minimal animation
