# design.md — Visual Design System 
 
 ## Principle 
 Plain, simple, high-contrast, large touch targets. Every feature lives in a clearly 
 bordered box/card — no hidden menus, no ambiguous icons without labels. 
 
 ## Color palette 
 
 | Role | Color | Hex | 
 |---|---|---| 
 | Primary (brand/action) | Deep leaf green | #2D6A4F | 
 | Primary dark (headers) | Forest green | #1B4332 | 
 | Background | Off-white | #F8FAF7 | 
 | Card background | Soft green tint | #F1F7F3 | 
 | Alert/Warning | Amber | #F4A300 | 
 | Critical alert | Red | #D64545 | 
 | Text primary | Charcoal | #222222 | 
 
 ## Typography 
 - Font: Inter or Poppins (Google Fonts, free) 
 - Base size: 16px minimum body text 
 - Headings bold, generous line-height 
 
 ## Layout rules 
 - Every module = a bordered, rounded card (rounded-xl, soft shadow) 
 - Icons always paired with text labels, never icon-only buttons 
 - Mobile-first responsive layout 
 - Minimal animation — simple fade/slide only 
 - Language switcher visible and accessible from every screen
